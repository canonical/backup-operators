# Backup server Terraform product module
<!-- vale Canonical.007-Headings-sentence-case = YES -->

This folder contains the [Terraform][Terraform] product module for the Bacula backup server. It
deploys a ready-to-use backup server with the [Terraform Juju provider][Terraform Juju provider]
into the machine model given by `model_uuid`:

- `bacula-server`, the Bacula director and storage daemon.
- `postgresql`, the Bacula catalog database.
- `s3-integrator`, the S3 bucket backups are stored in.

The module offers the `bacula-dir` endpoint of `bacula-server`. `bacula-fd` and
`backup-integrator` aren't part of the product: deploy them next to each workload to back up,
then integrate `bacula-fd` with the `bacula_dir` offer from the `offers` output. Add the Juju
users of other models to `bacula_dir_offer_consumers` to let them consume the offer.

The bundled `postgresql` and `s3-integrator` are optional. Set `postgresql_integration` or
`s3_integration` to an existing application `name` in the model or to an `offer_url`, and the
module integrates `bacula-server` with it instead of deploying its own.

`risk` sets the channel risk of every bundled charm whose `channel` is left unset.
`bacula-server` is published on `edge` only, so set `risk = "edge"` until it's released to
`stable`.

The bundled `s3-integrator` needs its credentials set after deployment with the
`sync-s3-credentials` action.

## Module structure

- **main.tf** - Defines the Juju applications, offers and integrations of the solution.
- **locals.tf** - Derives the charm channels from `risk` and selects the integration targets.
- **variables.tf** - Allows customization of the deployment, including the revision of every
  bundled charm.
- **outputs.tf** - Exposes the deployed `models`, the `offers` and the deployment `metadata`.
- **terraform.tf** - Defines the Terraform and Juju provider versions.

## Using the backup server product module

Always pin the `?ref=` to a released tag or a commit hash: CC008 does not allow floating
references such as branches.

```text
data "juju_model" "backup" {
  name  = "backup"
  owner = "admin"
}

module "backup_server" {
  source = "git::https://github.com/canonical/backup-operators//terraform/product?ref=backup-server-tf-1.0.0"

  model_uuid = data.juju_model.backup.uuid
  risk       = "edge"
}

resource "juju_integration" "bacula_fd" {
  model_uuid = data.juju_model.workload.uuid

  application {
    name     = module.bacula_fd.application.name
    endpoint = module.bacula_fd.requires.bacula_dir.endpoint
  }

  application {
    offer_url = module.backup_server.offers.bacula_dir
  }
}
```
